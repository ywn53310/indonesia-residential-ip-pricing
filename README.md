## 三种“印尼住宅IP”，价差三倍是常态

搜这个词会看到几十元一个月的，也有一百多、两百的。同样写着印尼，IP 的出身可能完全不同。

**家宽住宅 IP**：当地 ISP 分配给家庭宽带用户的地址，ASN 和 whois 落在运营商的家用网段里。这类资源在印尼 VPS 市场属于稀缺品，供应商拿货成本高，卖得也贵。

**原生 IP（机房商宽）**：IP 注册地和机房位置一致，但网段属于机房或云服务商。国内有商家把这两类摆在同一页上卖，价差很直观：朝暮数据雅加达 R 区标“原生IP”，1 核 1GB / 20GB / 100Mbps / 不限流量，55 元/月起；同一页面的 i 区标“住宅IP”，168 元/月起。三倍左右的差价，买的就是“这段地址属于谁”。

**中转落地的伪原生**：机器实际在别处，出口经印尼节点转发出去，检测工具看着像印尼，实际带宽多人共享、地址轮换，续费或换 IP 还要另外加钱。

行业里术语混用的情况相当普遍。一些主打住宅 IP 的商家，官网明确归入“家宽住宅”分类的只有香港、日本、英国、新加坡、马来西亚五个地区，印尼只出现在“BGP 原生双 ISP”机房线里。双 ISP 的 IP 在很多数据库里确实显示为住宅，跑 TikTok 也不差，它和运营商拉进居民家里的那条宽带仍然是两回事。买之前看清商家把它归在哪一类，比看宣传语有用。

价格上有个大致参照：印尼方向的原生住宅资源，单台月付常见在几十到两百元人民币之间，独享带宽越高越贵。明显低于这个区间的，通常在三处缩水，共享带宽、地址多人轮换、更换收费。打着“一次性收费永久使用”的，多半是短期池。

## 买前自检：三步确认拿到的是不是真家宽

**第一步，查 IP 归属和 ASN。** 拿到机器后用 ipinfo 一类工具看 ASN 是不是印尼本地运营商，org 字段是不是机房名称。家宽段和机房段的差别，在这一步最明显。

**第二步，确认多源检测查的是同一个出口 IP。** 同一个 IP 在 A 平台显示 Residential、在 B 平台显示 Proxy 甚至 Hosting，这种情况很常见，标签并存本身不代表线路有问题。先确认几个平台查的是同一段地址，再交叉看 ISP、ASN 和 Abuse 记录。

**第三步，别把单一欺诈评分当判决书。** 这类评分没有统一的计算依据，不同站点给同一个 IP 的分值能差出一大截。TikTok 有自己的 IP 库和检测手段，第三方分数只能当参考，不能当结论。

如果商家公开了测试 IP，下单前先自己跑一遍上面三步，比看任何测评都直接。
